Layout Probe – Every Rendered Surface

A stylesheet test document. It computes nothing and reads nothing.

Author

Matthias Uckert

Published

August 19, 2026

Purpose

This document exists to be looked at. It computes nothing, reads no artifact and writes no output. Every block below is a surface that _styles.css has to render well, filled with synthetic values so the page can be judged without waiting hours for a pipeline stage to finish.

Render it after any change to _styles.css or to the html block of _quarto.yml, from the project root:

quarto render 1_code/_Tests/layout-probe.qmd

It lives under _Tests/, which Quarto ignores when the project is rendered as a whole, so it is never built by accident and never appears on the site.

What is being checked

Seven things, in the order a reader meets them.

  1. The fixed rail at four levels of heading, which is the depth toc-depth allows.
  2. Console blocks: the fixed-width tables from tbl_say(), which arrive tagged as standard error because cli writes through the message stream.
  3. The same tables on the rendered path, with grouped headers, a summary row and footnotes.
  4. tbl_note() output, which is a paragraph rather than a console line.
  5. Figures at three rungs of the height ladder.
  6. Folded source, inline code, and a long unfoldable line.
  7. Lists, links and block quotes, which appear rarely enough to be forgotten.

Why it is not a pair

Every analysis step in this repository is a .qmd and a .R sharing a stem. This is not an analysis step. Its content is deliberately inline, because the thing under test is what the markup looks like, and hiding the calls that produce it in a library would make the document harder to reason about rather than easier.

Notes on their own

tbl_note() on the rendered path emits a paragraph rather than a console alert, because a finding about a table is prose about the table. A cli alert would arrive as a monospaced block that does not wrap, so a sentence longer than the page would need dragging through a scroll bar to be read.

.mode_was <- getOption("mc.table_mode")
options(mc.table_mode = "kable")

tbl_note(
  .text = "The two windows part company on 312 documents, which is 7.1 per cent of the sample and \\
           the entire difference between the two columns above."
)

Figures

Three rungs of the ladder in plot_height(), so the relationship between row count and canvas can be judged on one page. Width is fixed globally in _quarto.yml and is never set per chunk.

plot_bar_ranked(
  .tab   = dplyr::filter(tab_main, .data$Class != "All"),   # the summary row is not a category
  .cat   = "Class",                                          # the categorical axis
  .val   = "Documents",                                      # the measured value
  .key   = "Class",                                          # registered vocabulary, for stable order
  .label = TRUE                                              # value labels at the end of each bar
)

Every chunk above is folded by default. The toggle should read as a control rather than as a line of code that happens to be there.

Inline code

A sentence carrying ner_db_summary(), a path like 2_output/04A-EntityExtract/Store/, and a parameter such as .lP$Param$ChunkSize, so inline code can be judged in running prose rather than on its own line.

Prose surfaces

Lists

Ordered, for a sequence:

  1. Read the label spine and assert the identifier joins.
  2. Deal the folds once, upstream, and never re-deal them.
  3. Score every arm on the same folds with the same code.

Unordered, for a set:

  • Single-writer rule. Exactly one script writes any given artifact.
  • Unconditional checks. Every validation runs on every render.
  • Gated network calls. Only acquisition is behind a switch; local computation never is.

A block quote

A document that silently skips its own work will report numbers computed from inputs that no longer exist, and will look entirely normal doing it.

Links and emphasis

A link to the EDGAR full-text search, some bold text, some italic text, and a horizontal rule below.
